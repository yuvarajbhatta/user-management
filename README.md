# User Management System - Spring Boot MVC App

A basic user management application using Spring Boot, MySQL, Thymeleaf, and the MVC pattern.

## Features
- Add a user
- View all users
- Simple HTML UI with Thymeleaf

## Technologies Used
- Java 17
- Spring Boot 3.5
- Spring Data JPA
- Thymeleaf
- MySQL
- IntelliJ IDEA
